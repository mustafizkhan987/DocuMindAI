## Objective
Redesign the Android application to embody a professional, trustworthy, and serious document management tool. Target usability accommodates office staff, accountants, and older demographics by avoiding flashy startup elements in favor of Material 3 components with high-contrast elements, clear typography, and simplified workflows.

## Existing UI Problems
The previous UI (mostly `FoundationScreen`) looked like a tech demo with neon animations, glowing gradients, and tiny text sizes. It lacked navigation, clear document extraction steps, and intuitive result screens.

## Design Direction
- **Brand Colors:** Shifted to a deep professional navy (`#0F2046`), muted teal, and semantic status colors (green for valid, amber for review, red for errors).
- **Backgrounds:** Transitioned from dark gradients to clean, light neutral backgrounds with white cards.
- **Typography:** Adopted clear hierarchy utilizing `MaterialTheme.typography` with readable font sizes for aging eyes.

## Accessibility Decisions
- Buttons and cards maintain large, thumb-friendly touch targets.
- Jargon-heavy terms ("inference", "OCR models") replaced with layman terms ("reading document", "extracting text").
- Statuses are explicitly declared in badges alongside icons (e.g. `Information extracted`, `Review required`), avoiding color-only indicators.

## Screens Redesigned
1. `HomeScreen`: Welcome banner, simple primary action (Upload), and clear recent documents view.
2. `DocumentsScreen`: Document listing with search functionality and a structured Empty State.
3. `UploadScreen`: Document picker interface with clear instructions and fallback state documentation.
4. `ProcessingScreen`: Deterministic visual progression showing extraction steps (Upload -> Enhance -> Extract -> Identify) instead of raw spinning loaders.
5. `DocumentResultScreen`: Detailed key-value rows separating pure extraction ("Information Found") from active validation.
6. `SettingsScreen`: Standard preferences structure.
7. `AboutScreen`: Explicit transparency about DocuMind AI's independent status to establish trust without mimicking government applications.

## Components Created
- `DocuMindPrimaryButton.kt`: Standardized large action button.
